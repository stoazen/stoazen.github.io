# 使用指南

StoaZen App 有五個分頁：抽卡、禪修、收藏、紀錄與設定。

## 抽卡

1. 回答「此刻，你在為什麼而困擾？」，從八個主題或「隨緣」中選一個。
2. 按下「抽一張」。
3. 點擊卡片翻面，閱讀白話解說；可以收藏、分享，或再抽一張。

抽卡沒有每日次數限制。系統會優先給你還沒看過的卡；同一個主題的卡都看過之後，才會再次出現看過的卡，並標示為「重逢」，也會避開你最近剛抽到的幾張。

## 禪修

三種靜默練習，可選擇 1、5、10 或 20 分鐘：

- **呼吸**：跟著墨圈的漲落，吸氣、吐氣
- **數息**：吐氣時數一次，一到十再重來
- **只管打坐**：什麼都不做，就只是坐著

禪修沒有語音與背景音樂，開始與結束時各有一次輕微震動，過程中螢幕保持開啟。卡片頁也有「禪修一分鐘」的捷徑。

禪修會記錄在月曆與累計時間中，但**不給經驗值，也不計算連續天數**。

## 收藏

在卡片上按下收藏，卡片就會留在收藏分頁。可以依主題或流派篩選，也能用關鍵字搜尋金句與作者。

## 紀錄

- **成長**：等級、經驗值進度、連續抽卡天數、圖鑑進度（看過幾張卡）、徽章與抽卡歷史，以及累計禪修時間
- **月曆**：每天抽到的卡與禪修次數，點選有標記的日期可以看當天的卡片；並整理出這個月你最常為哪個主題抽卡

## 經驗值與等級

| 行為 | 經驗值 |
| --- | --- |
| 每日第一次抽卡 | 20 |
| 抽到新卡 | 10 |
| 翻面閱讀解說 | 5 |
| 收藏 | 5 |
| 抽到看過的卡 | 2 |

每天最多累積 60 點，抽卡本身不設限。連續抽卡達 3、7、30、100 天時，會另外獲得里程碑獎勵，不受每日上限影響。

等級只用來解鎖外觀，不會鎖住任何內容。隨等級解鎖的卡面材質：

| 等級 | 卡面 |
| --- | --- |
| Lv1 | 宣紙 |
| Lv2 | 麻布 |
| Lv3 | 水墨 |
| Lv5 | 竹簡 |
| Lv8 | 大理石 |
| Lv11 | 絹本 |
| Lv16 | 泥金 |
| Lv20 | 藏經紙 |

## 每日提醒

在設定中開啟每日提醒，選擇時間與主題，每天會收到一則來自該主題的金句通知，點開即可看到完整卡片。若系統已關閉 StoaZen 的通知權限，設定頁會提供前往系統設定的捷徑。

## 語言

介面與金句內容皆提供繁體中文與英文，可在設定中切換。
