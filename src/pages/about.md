# 關於 StoaZen 斯多禪

StoaZen 斯多禪收集了禪語、斯多葛哲學與心理學的智慧金句，為在人生路上感到困擾、焦慮或卡關的你而做。

名字取自 **斯多葛（Stoa）** 與 **禪（Zen）**。兩者相隔兩千年、東西兩端，卻問著同一個問題：當外在的事無法掌控，人要怎麼安頓自己？

## 我們在做什麼

StoaZen 的核心是一個「錦囊」。心裡有事的時候，選一個最貼近此刻的困擾，抽一張卡，讓一句話陪你換個角度看；想靜下來的時候，跟著呼吸禪修一分鐘，把注意力帶回當下。

目前收錄 180 則金句，分屬三個流派：

- **禪語**：六祖壇經、信心銘、臨濟錄、無門關等禪宗典籍
- **斯多葛哲學**：愛比克泰德、塞內卡、馬可・奧理略
- **心理學**：威廉・詹姆士、維克多・弗蘭克、佛洛伊德、卡爾・羅哲斯、阿德勒、榮格等

內容取自公有領域典籍與可引用之短句，每張卡片都標註作者與出處，並附上白話解說與英文對照。

## 產品

**StoaZen App（iOS / Android，即將上架）**

- 主題抽卡：焦慮不安、憤怒與衝突、拖延與行動、失落與挫敗、抉擇與迷惘、人際關係、自我懷疑、放下與無常，以及不設主題的「隨緣」
- 靜默禪修：呼吸、數息、只管打坐，可選擇時長
- 收藏：依主題或流派篩選，並可搜尋金句與作者
- 紀錄：月曆、抽卡歷史、圖鑑進度與等級
- 每日提醒、分享卡片、八種卡面材質、中英雙語介面

## 幾個堅持

- **內容不設門檻。** 等級只解鎖外觀，不會擋住任何一張卡。
- **禪修只記錄，不計分。** 安靜下來這件事，不該帶著「斷掉」的壓力。
- **資料留在你的手機。** 不需註冊帳號，收藏與紀錄只存在裝置上。
